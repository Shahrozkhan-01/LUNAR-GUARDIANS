# NASA OSD-53 / GLDS-53

OSD-53, **Spaceflight Modulates Gene Expression in Astronauts**, is a
historical human astronaut research study from NASA's Open Science Data
Repository. It contains 13 public sample annotations and processed
gene-expression summaries for pre-flight, post-flight, and control samples.

- [Official study page](https://osdr.nasa.gov/bio/repo/data/studies/OSD-53)
- [Official OSDR study API](https://osdr.nasa.gov/geode-py/ws/repo/studies/OSD-53)
- Organism: *Homo sapiens*
- GeneLab ID: `GLDS-53`
- Source accession: `E-GEOD-47126`

The raw microarray data are reported unavailable by OSDR. The project therefore
preserves only public processed archives, ISA metadata, API file metadata, and
study metadata. Missing source fields remain blank. Processed outputs contain
sample identifiers and phase metadata but remove study-subject labels.

The Data Explorer presents sample counts, pre-flight/post-flight counts, source
processed gene-expression summary metadata, and historical study limitations.
These data are not diagnoses, health predictions, lunar-crew measurements, or
gameplay health inputs.
